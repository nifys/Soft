# NIFY MENU — Android Studio + GitHub Actions

Тестовая плавающая панель для Android. Это отдельное приложение: оно **не внедряется в Standoff 2**, не читает память игры и не взаимодействует с её античитом.

## Функции
- Плавающая панель, которую можно перетаскивать.
- Тестовый центральный прицел поверх окон.
- UI-параметры размера прицела, цветовая тема и компактный режим.
- Demo FPS label (не измеряет FPS Standoff 2).
- `Aimbot simulation` и `Wallhack simulation` — безопасные демонстрационные переключатели, не дающие игровых преимуществ.

## Открыть в Android Studio
1. Распакуйте ZIP.
2. Android Studio → Open → выберите папку `NIFY-MENU`.
3. Дождитесь синхронизации Gradle.
4. Запустите приложение на устройстве Android.
5. Нажмите разрешение «Отображение поверх других приложений», затем запустите меню.

## Сборка локально
Нужны JDK 17 и Android SDK Platform 35:
```bash
gradle assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка через GitHub Actions
1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите содержимое этой папки в корень репозитория (папка `.github` должна попасть в репозиторий).
3. Откройте вкладку **Actions** и разрешите workflow, если GitHub попросит.
4. Запустите `Build NIFY MENU APK` через **Run workflow** или сделайте push в `main`.
5. Откройте завершённый запуск и скачайте `NIFY-MENU-debug-apk` в разделе **Artifacts**.

Артефакт — debug APK для тестирования, не подписанный релизный APK.

## Ограничения
- Overlay может быть запрещён системой, отключён производителем устройства или не отображаться в полноэкранном режиме на некоторых устройствах.
- Android 13+ может требовать разрешение на уведомления в зависимости от устройства и настроек.
- `Demo FPS` — только статусный индикатор; стороннее приложение не может надёжно показывать FPS другой игры без поддерживаемого API.
- Реальный aimbot/wallhack для Standoff 2 не реализованы. Переключатели обозначают только sandbox mock UI.
